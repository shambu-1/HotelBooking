# HotelBooking
## Tech Stack
- **Framework:** Angular (Standalone Components, Signals)
- **Language:** TypeScript
- **Styling:** Vanilla CSS (no heavy external UI libraries)
- **Testing:** Jasmine / Karma (or Vitest)

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Installation & Run
1. Install dependencies:
   ```bash
   npm install
2. Run the app:
    ```bash
    npm start
